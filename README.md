# 3-Actor Predator–Prey System

2D cellular-automata style game — final project for the course SI1336 Simulation and Modeling at KTH.

A small, pure-Python Tkinter simulation showing simple predator–prey interactions on a grid. The implementation is compact and intended for learning, experimenting and demos.

## Key points
- Pure Python (Tkinter) GUI, no extra packages required.
- Grid-based simulation with two actor types by default: Herbivores and LowPredators.
- Fast to run and easy to modify — tweak parameters in cellular_game.py.

## Requirements
- Python 3.8+ with Tkinter available (on some Linux distros you may need to install `python3-tk`).

## Run
From a clone of the repo:
```bash
python cellular_game.py
